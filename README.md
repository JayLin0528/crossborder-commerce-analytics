# 跨境罗盘：多平台电商数据分析 App

一个可直接运行的跨境电商订单分析看板。它将 Amazon、Shopify、TikTok Shop、eBay 等平台的订单汇总到同一口径，帮助运营人员查看销售、利润、市场和商品表现。

**[在线体验 App](https://jaylin0528.github.io/crossborder-commerce-analytics/)**

> 当前版本是前端原型。所有数据在浏览器本地处理；没有平台 API 对接、账号系统或服务器存储。

## 快速体验

1. 打开仓库根目录的 `index.html`。页面默认加载合成示例数据。
2. 点击 **自动演示**，观看 CSV 导入、平台筛选、市场筛选和商品分析流程。
3. 点击 **下载 CSV 模板**，按模板填写订单数据后点击 **导入订单 CSV**。

也可以导入 [`examples/orders.csv`](examples/orders.csv) 试用多币种折算。该文件全部是虚构数据，汇率仅供功能演示。

运行检查：安装 Node.js 后执行 `npm test`。无需安装依赖。

## 功能

- 多平台订单汇总，按日期、平台、国家 / 地区筛选。
- 统一折算为 USD，显示净销售额、估算利润、订单数和利润率。
- 销售与利润趋势、平台贡献、市场表现和 SKU 排名。
- CSV 模板下载、导入校验、重复记录去重、筛选结果导出。
- 自动演示流程；结束时恢复先前数据和筛选条件。
- 响应式布局，手机和桌面均可使用。

## 数据格式与指标口径

每一行是一条订单商品记录。必填列为 `order_id,date,platform,country,revenue`，日期格式为 `YYYY-MM-DD`。建议同时填写 `sku,product,quantity,currency,product_cost,shipping_cost,ad_spend,platform_fee,refund_amount,fx_to_usd`。

`fx_to_usd` 表示 **1 单位原币可兑换多少 USD**。USD 可留空，非 USD 必须填写。收入和成本均乘以该汇率。非美元订单缺少汇率、金额格式错误或缺少必填信息时会跳过，并在页面显示数据质量提示。缺失成本列按 0 计算，此时利润仅供参考。

| 指标 | 计算方式 |
| --- | --- |
| 净销售额 | 销售额 − 退款金额 |
| 估算利润 | 净销售额 − 商品成本 − 物流成本 − 广告费 − 平台费用 |
| 订单数 | `platform + order_id` 去重计数 |
| 利润率 | 估算利润 ÷ 净销售额 |

导出的筛选结果已折算为 USD，`currency` 固定为 `USD`，`fx_to_usd` 固定为 `1`，可再次导入而不会重复换汇。页面刷新后恢复合成示例数据，不会保存导入的文件。

## 技术与验证

使用原生 HTML、CSS 和 JavaScript 实现，零运行时依赖。测试使用 Node.js 内置测试运行器，覆盖 CSV 引号处理、汇率折算、重复记录、利润口径、缺失汇率及自动演示的状态恢复。

这个项目面向可快速验证的数据分析场景。后续可增加平台 API 同步、持久化数据库、权限控制、历史汇率服务和更完整的退款 / 税费核算。
